# Fixed functional samples

`fog.mp4`, `rain.mp4`, `snow.mp4` each contain three copies of a retained local demo image, resized to 128×96 and encoded as H.264 at 6 FPS. They test upload, weather routing, enhancement, detection, browser playback and repeatability. They are not independent evaluation datasets or a temporal-quality benchmark.

Source images: `frontend/image_display/fog1.jpg`, `rain1.jpg`, `snow1.jpg`. Generation and checksum recording are implemented by `scripts/validate.py`. Original image provenance remains unverified.
